# V3 Results — Advanced Prompt Engineering & Evaluation

## Prompt Used

The V3 prompt was tested using the same Junior AI Support Specialist job description used in V1 and V2.

V3 introduced:

* Evidence grounding
* Explicit uncertainty handling
* Separation of facts and recommendations
* Structured extraction
* Quality-control checks
* Output scoring
* Instructions to avoid unsupported applicant assumptions

## AI Output

The prompt was tested using Claude.

The complete V3 analysis is documented below.

### 1. Executive Summary

The model identified that the role focuses on supporting users of AI-powered software, responding to technical issues, documenting problems and solutions, testing AI features, and improving AI-assisted workflows.

### 2. Technical Skills

The model identified:

* Basic AI/ML understanding
* Basic computer skills
* Python
* Data analysis
* Prompt engineering
* Generative AI tools
* GitHub
* Basic automation knowledge

It also distinguished between required and advantageous skills.

### 3. Soft Skills

The model identified:

* Written and verbal communication
* Problem-solving
* Ability to learn new technologies quickly
* Attention to detail
* Ability to work independently and as part of a team

### 4. Priority Keywords

The model ranked five priority keywords based on their relevance to the job description.

### 5. Required vs Advantageous

The model clearly separated the employer's required skills from the advantageous skills.

### 6. Evidence vs Recommendations

The model separated information directly supported by the job description from recommendations made by the AI.

### 7. Applicant Skill-Gap Analysis

The model correctly stated that no applicant information had been provided and therefore a reliable skill-gap analysis could not be performed.

### 8. Uncertainty and Quality Check

The model identified ambiguity in requirements such as:

* "Basic understanding of artificial intelligence and machine learning concepts"
* "Basic computer skills"

It also identified information that could not be determined from the job description.

## Comparison With V1 and V2

### V1

The baseline prompt produced a useful but relatively general response.

### V2

The structured prompt improved organisation, prioritisation, and control over unsupported assumptions.

### V3

The advanced prompt added evidence grounding, uncertainty detection, separation of facts from recommendations, and an explicit evaluation framework.

## Key Finding

The experiment demonstrates that increasing prompt specificity can change not only the format of an LLM response, but also how the model handles evidence, uncertainty, assumptions, and evaluation.

## Limitations

The experiment has several limitations:

1. Only one example job description was used.
2. The experiment used one primary LLM environment.
3. The quality scores were generated by the model itself and therefore should not be treated as independent evaluation.
4. More test cases would be required to determine whether the prompt improvements generalise to other job descriptions.

## Conclusion

V3 produced the most controlled and transparent output of the three prompt versions.

The experiment demonstrates practical prompt-engineering techniques including structured prompting, evidence grounding, constraint design, uncertainty handling, and LLM output evaluation.
